HWP Editor 제거기는 사용자가 만든 문서나 공유 런타임을 실수로 지우지 않도록 **설치 영수증(`hwp-user-install-receipt-v2`)과 핵심 파일 4종을 사전 검증**한 뒤에만 앱 폴더를 정리합니다.

## 안전 제거 방법

제거를 시작하기 전에 실행 중인 **`HWPReview.exe`를 먼저 종료**하세요.

<Tabs items={['Windows 설정에서 제거 (권장)', 'PowerShell 스크립트 실행']}>
  <Tab value="Windows 설정에서 제거 (권장)">
    1. **Windows 설정 → 앱 → 설치된 앱**을 엽니다.
    2. 목록에서 **HWP Editor**를 찾아 **제거**를 클릭합니다.
    3. 설치 영수증과 해시가 일치하는 앱 파일·시작 메뉴 바로가기·현재 사용자 제거 등록을 정리합니다. 변경되거나 추가된 파일은 남깁니다.
  </Tab>

  <Tab value="PowerShell 스크립트 실행">
    설치 폴더에 있는 제거 스크립트를 실행합니다. 다른 버전의 키트에 포함된 스크립트로 섞어 실행하지 마세요.

    ```powershell
    powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Programs\HWPReview\Uninstall-HWPReview.ps1"
    ```
  </Tab>
</Tabs>

### 제거 시 삭제되는 항목 vs 보존되는 항목

| 구분 | 대상 | 처리 |
| --- | --- | --- |
| 제거 대상 | `%LOCALAPPDATA%\Programs\HWPReview`의 설치 파일 | 영수증과 바이트가 일치하는 파일만 제거합니다. 핵심 파일 4개는 삭제 전에 함께 검사하고, 폴더는 비었을 때만 제거합니다. |
| 제거 대상 | 시작 메뉴 **HWP Editor** 바로가기 및 HKCU 제거 등록 | 소유 기록과 일치할 때만 제거합니다. |
| **보존됨** | 사용자의 모든 `.hwpx` / `.hwp` 문서 및 작업 폴더 | **절대 삭제하지 않음** |
| **보존됨** | 작업 폴더 내 `.hwpreview/` (원본 백업 및 체크포인트) | **절대 삭제하지 않음** |
| **보존됨** | OMP 인증·설정(`%USERPROFILE%\.omp`, `%USERPROFILE%\.bun` 등) 및 실행 로그 | **절대 삭제하지 않음** |
| **보존됨** | `.NET 10`, `WebView2`, `PowerShell 7`, `D2Coding Nerd Font` 등 공유 런타임 | **절대 삭제하지 않음** |

<Callout type="info" title="예상치 못한 사용자 파일이 설치 폴더에 있을 때">
  만약 `%LOCALAPPDATA%\Programs\HWPReview` 안에 사용자가 직접 넣어 둔 알 수 없는 파일이 발견되면, 제거기는 데이터를 잃지 않기 위해 폴더를 강제 삭제하지 않고 보존한 채 종료 코드 **`3`**을 반환합니다.
</Callout>

## 설치 · 점검 로그 위치

설치, 제거, 필수 도구 점검이 실패하거나 원인을 추적해야 할 때는 아래 두 폴더의 최신 로그와 JSON 리포트를 확인하세요.

| 로그 폴더 | 기록 내용 |
| --- | --- |
| `%LOCALAPPDATA%\HWPReview\InstallRuns` | `Install-HWPReview.ps1` / `Uninstall-HWPReview.ps1` 실행 로그 및 결과 JSON |
| `%LOCALAPPDATA%\HwpReview\SetupRuns` | `Setup-Requirements.cmd` / `--setup-requirements` 필수 도구 5종 점검·설치 로그 |

PowerShell에서 최신 로그 폴더를 바로 열려면:

```powershell
explorer "$env:LOCALAPPDATA\HWPReview\InstallRuns"
explorer "$env:LOCALAPPDATA\HwpReview\SetupRuns"
```

## 종료 코드 레퍼런스 (`hwp-install-operation-v1`)

| 종료 코드 | 의미 | 권장 조치 |
| --- | --- | --- |
| `0` | 확인·설치·제거 성공 또는 동일 설치/이미 제거됨 | `status`의 `payload_valid_no_mutation`, `installed`, `uninstalled`, `already_installed`, `already_absent`를 구분하세요. |
| `1` | 일반 실행 실패 | `detail`과 생성된 로그를 확인합니다. |
| `3` | 경로·소유권·충돌 또는 변경/추가 파일 보존 | `detail`·`retained`를 확인하고 기존 설치 파일을 강제로 지우지 않습니다. |
| `4` | 제거하려는 앱이 실행 중 | 앱과 OMP를 정상 종료한 뒤 상태를 확인합니다. |
| `5` | 필수 도구 확인 또는 준비 실패 | `SetupRuns`의 로그와 종료 코드를 확인합니다. |
| `1602` | 필수 도구 준비가 취소됨 | 취소된 단계와 로그를 확인합니다. 다음 단계는 자동으로 실행되지 않습니다. |
| `3010` | 필수 도구 준비 중 재부팅 필요 | 앱 설치가 끝난 것이 아닙니다. 재부팅 후 설치 상태를 확인합니다. |
