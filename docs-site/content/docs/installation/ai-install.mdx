설치 킷에 포함된 **`AI-INSTALL.md`**는 사용자가 AI 도우미(예: OMP, Claude Code, Codex 등)에게 HWP Editor 설치나 상태 점검을 맡길 때 따라야 하는 **안전 규칙과 공식 명령어**를 정의합니다.

현재 공개 설치 ZIP은 게시되지 않았습니다. 아래 명령은 공개 키트가 제공된 뒤에만 적용합니다. 지금 사용하려면 [소스에서 실행](/docs/installation#소스에서-실행)을 따르세요.

## AI에게 설치를 맡길 때 지켜야 할 원칙

<Callout type="warn" title="비대화형·무단 실행 금지">
  - `.NET 10`과 `PowerShell 7`은 Windows **UAC(관리자 승인)** 창이 필요하므로, AI가 이를 우회하거나 백그라운드에서 강제 설치해서는 안 됩니다.
  - Microsoft Visual C++ v14 **x64 `14.51.36247.0` 이상**은 사용자가 먼저 준비합니다. 누락되면 [Microsoft 공식 x64 설치기](https://aka.ms/vc14/vc_redist.x64.exe)를 안내하고 사용자의 설치 완료를 기다리세요. AI나 앱 설치기가 이 런타임을 자동으로 다운로드·설치하지 않습니다.
  - AI는 항상 **읽기 전용 점검(`-Operation Check`)을 먼저 실행**하고, 결과를 사용자에게 보고한 뒤 명시적 승인을 받아 설치 단계를 진행해야 합니다.
  - 실패·타임아웃·충돌(종료 코드 `1`, `3`, `4`, `5`, `1602`)이 발생하면 자동 재시도하거나 기존 폴더를 강제 삭제하지 말고 즉시 중단해 로그 경로를 보고해야 합니다.
</Callout>

## 1단계: 읽기 전용 상태 점검 (`-Operation Check`)

압축을 푼 키트의 파일 목록·해시, 설치 경로와 기존 설치 충돌을 읽기 전용으로 검사합니다. EXE·필수 항목 확인기를 실행하지 않고 설치 파일·로그·레지스트리도 만들지 않습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-HWPReview.ps1 -Operation Check
```

### 주요 출력 필드 확인

- `contract`: `hwp-install-operation-v1`
- `status`: 새 설치 대상과 키트가 정상이면 `payload_valid_no_mutation`, 같은 키트가 정확히 설치돼 있으면 `already_installed`, 실패하면 `failed`입니다.
- `prerequisites_checked: false`: 이 명령의 성공은 필수 도구 준비 완료를 뜻하지 않습니다. 필수 도구만 확인하려면 `HWPReview.exe --check-requirements <새 절대 JSON 경로>`를 사용합니다.
- `exit_code`: `0`이면 확인 완료, `3`이면 경로·소유권·충돌로 차단됐습니다. 실패 시 `detail`을 읽으세요.

## 2단계: 사용자 승인 후 설치 실행

점검 결과에 충돌이 없고 사용자가 동의하면, 압축 해제된 폴더에서 공식 진입점만 실행합니다.

```powershell
# 앱 사용자 단위 설치
.\Install-HWPReview.cmd

# (설치 후) 앱 필수 도구와 선택적 한글 보안모듈 상태 JSON 점검
$report = Join-Path $env:TEMP "hwpreview-req-$([guid]::NewGuid()).json"
$process = Start-Process -FilePath "$env:LOCALAPPDATA\Programs\HWPReview\HWPReview.exe" `
  -ArgumentList '--check-requirements', ('"{0}"' -f $report) -Wait -PassThru
$process.ExitCode
if (Test-Path -LiteralPath $report) { Get-Content -LiteralPath $report -Raw }
```

필수 도구 중 누락된 항목이 있다면(`exit_code == 2`) 사용자에게 누락 목록과 UAC 필요 여부를 안내한 뒤 **`Setup-Requirements.cmd`**(또는 `HWPReview.exe --setup-requirements`)를 실행하도록 합니다.

한글 자동화 보안모듈은 호환 x86 한글에서만 적용되며, 사용자가 고지를 읽고 직접 동의해야 합니다. AI가 동의를 대신하거나 비호환 환경에 설치하지 마세요. [선택적 한글 보안모듈 안내](/docs/installation/prerequisites#한글-자동화-보안모듈-선택)

## AI에게 전달할 프롬프트 예시

```text
다운로드해서 압축을 푼 HWPReview 설치 폴더에서 AI-INSTALL.md 규칙을 따라줘.
1) 먼저 Install-HWPReview.ps1 -Operation Check로 현재 상태만 읽기 전용으로 확인하고 결과를 알려줘.
2) 충돌이나 오류가 있으면 임의로 수정하지 말고 멈춰서 detail과, 로그가 있다면 그 경로를 알려줘.
3) 내 확인을 받은 뒤에만 Install-HWPReview.cmd와 필수 도구 점검을 진행해줘.
```
