HWP Editor는 앱 본체 외에 **5종의 고정 버전(pinned) 외부 도구**를 사용합니다. 라이선스와 보안 경계를 지키기 위해 이 도구들은 ZIP 설치 킷 안에 임의로 묶지 않고, **설치 시 현재 PC에 없는 항목만 공식 배포처에서 다운로드한 뒤 해시·서명 검증을 거쳐 설치**합니다.

## Microsoft Visual C++ v14 런타임 (별도 선행 설치)

설치기나 `HWPReview.exe`를 실행하기 전에 Microsoft Visual C++ v14 재배포 가능 패키지 **x64 `14.51.36247.0` 이상**이 설치되어 있어야 합니다. 없거나 버전이 낮다면 [Microsoft 공식 안내](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)에서 확인하고 [공식 x64 설치기(`vc_redist.x64.exe`)](https://aka.ms/vc14/vc_redist.x64.exe)를 사용자가 직접 실행하세요.

이 런타임은 아래 5종과 별개입니다. 개별 DLL과 런타임 설치기는 배포 ZIP에 없으며, HWP Editor는 이를 자동으로 다운로드하거나 설치하지 않습니다.

<Callout type="info" title="기존 환경 존중 원칙">
  이미 호환되는 버전이 PC에 설치되어 있으면 설치기는 해당 도구를 건너뛰고 기존 구성을 그대로 사용합니다.
</Callout>

## 필수 도구 5종 명세 (`windows-dependencies.json` 기준)

| --- | --- | --- | --- | --- | --- |
| 1 | **.NET 10 Desktop Runtime (x64)** | `10.0.14` | Microsoft 공식 WindowsDesktop 런타임 | 필요 (UAC) | WPF 네이티브 앱(`HWPReview.exe`) 실행 |
| 2 | **Microsoft Edge WebView2 Runtime** | `156.0.4314.58` (Evergreen) | 고정 버전의 Microsoft Evergreen 설치기 | 환경에 따라 필요 | 내장 `.hwpx` 라이브 미리보기 및 `xterm.js` 렌더링 |
| 3 | **Bun & oh-my-pi (OMP)** | `Bun 1.4.4` / `OMP 18.15.0` | 기존 `%USERPROFILE%\.bun` 재사용 또는 앱 전용 격리 설치 | 불필요 (사용자) | 우측 패널 OMP TUI 및 AI 문서 작업 실행 |
| 4 | **PowerShell 7 (x64)** | `7.6.9` | Microsoft 공식 MSI (대화형 설치) | 필요 (UAC) | OMP 도구 실행 및 현대적 UTF-8 Windows 셸 환경 |
| 5 | **D2Coding Nerd Font Propo** | `3.5.1` (`D2KodingLigature Nerd Font Propo`) | 사용자 글꼴 폴더(Regular / Bold) | 불필요 (사용자) | OMP TUI의 한글·고정폭 정렬 및 Nerd Font 아이콘 표시 |

## 도구별 상세 동작 및 주의 사항

### 1. .NET 10 Desktop Runtime (x64, `10.0.14`)
- 일반 `.NET Runtime`이 아니라 **`WindowsDesktop` 런타임(`Microsoft.WindowsDesktop.App` 10.x x64)**이 필요합니다.
- 설치 시 관리자 권한(UAC) 승인이 필요합니다.

### 2. Microsoft Edge WebView2 Runtime (`156.0.4314.58` Evergreen)
- Windows 11에는 대부분 기본 포함되어 있으며, 이미 설치된 경우 자동으로 건너뜁니다.
- 누락되면 고정 Microsoft Evergreen 설치기를 확인합니다. 원문 약관과 SmartScreen 정보 전송·자동 업데이트 안내를 읽고, 설치 범위는 Microsoft 공유 Updater의 판단을 따릅니다.

### 3. Bun `1.4.4` & oh-my-pi (`OMP`) `18.15.0`
- 기존 앱 전용 런타임이 있으면 먼저 검증합니다. 해당 설치가 손상됐거나 일부만 남았으면 다른 경로로 우회하지 않습니다.
- 앱 전용 런타임이 없으면 정확한 `%USERPROFILE%\.bun`을 재사용합니다. 둘 다 없으면 사용자 전역 Bun 환경을 덮어쓰지 않고 아래 격리 경로를 준비합니다.
  ```text
  %LOCALAPPDATA%\HWPReview\Dependencies\Bun-1.4.4-OMP-18.15.0
  ```
- 설치 시 패키지 **라이프사이클 스크립트 실행을 비활성화**하고, 런타임 핵심 파일 **21개**의 존재와 무결성을 검증합니다.

### 4. PowerShell 7 (`7.6.9` x64 MSI)
- Windows 기본 내장 PowerShell 5.1(`powershell.exe`)을 제거하거나 덮어쓰지 않습니다.
- 공식 MSI가 대화형으로 실행되며, 기본 설정에서 불필요한 시스템 PATH 강제 변경·원격 관리(Remoting)·자동 업데이트는 꺼진 상태를 유지합니다.

### 5. D2Coding Nerd Font Propo (`3.5.1`)
- `D2KodingLigature Nerd Font Propo` **Regular / Bold** 글꼴을 현재 사용자 Windows 글꼴 폴더에 설치합니다.
- `terminal.js`에서 터미널 기본 폴백 글꼴로 지정되어 있어, 한글과 OMP 상태 표시줄의 Nerd Font 글리프가 깨지지 않고 정렬됩니다.

## 한글 자동화 보안모듈 (선택)

- 호환되는 x86(32비트) 한컴 한글이 설치된 경우에만, 필수 환경 준비 창에서 고지를 읽고 명시적으로 동의하면 [한컴 공식 배포처](https://developer.hancom.com/hwpautomation)의 모듈을 HTTPS로 받아 검증한 뒤 현재 사용자에게 등록합니다. 한글 앱과 DLL은 배포 ZIP에 포함되지 않습니다.
- 이 모듈은 한글 자동화의 파일 접근 확인창을 생략합니다. 호환되는 한글이 없으면 적용 대상이 아니며, 일반 HWPX 미리보기·편집에는 필요하지 않습니다. 기존 정상 등록은 유지하며 충돌·손상 상태는 자동으로 수리하지 않습니다.
- 한글 오토메이션의 개인 비상업적 이용 범위는 한컴 안내를 확인하세요. 상업적으로 이용하려면 [한컴의 별도 승인과 라이선스](https://developer.hancom.com/support/buy-support/?category=3)가 필요합니다.

## 필수 도구 상태 점검 및 재설치 방법

<Tabs items={['상태만 확인 (CLI)', '누락 항목 준비 (설치 창)']}>
  <Tab value="상태만 확인 (CLI)">
    `--check-requirements`는 앱의 필수 도구 5종과 선택적 한글 보안모듈 상태를 새 `hwp-requirements-status-v2` JSON 파일에 기록합니다. 각 항목의 적용 여부와 설치 상태를 구분하며, 앱 창이나 설치기를 열거나 설정을 변경하지 않습니다. 별도 Visual C++ 런타임은 이 명령을 실행하기 전에 준비해야 합니다.

    ```powershell
    $report = Join-Path $env:TEMP "hwpreview-req-$([guid]::NewGuid()).json"
    $process = Start-Process -FilePath "$env:LOCALAPPDATA\Programs\HWPReview\HWPReview.exe" `
      -ArgumentList '--check-requirements', ('"{0}"' -f $report) -Wait -PassThru
    $process.ExitCode
    if (Test-Path -LiteralPath $report) { Get-Content -LiteralPath $report -Raw }
    ```

    `--check-requirements` 종료 코드:
    - `0`: 적용되는 필수 항목 준비 완료
    - `2`: 적용되는 항목에 미설치·버전 불일치·등록 문제 등이 있음(JSON의 `components` 확인)
    - `1`: 점검 중 오류 발생 (예: 이미 존재하는 파일 경로를 덮어쓰려 한 경우 등)
  </Tab>

  <Tab value="누락 항목 준비 (설치 창)">
    아래 세 가지 방법은 **같은 필수 환경 준비 창**을 엽니다. 상태만 확인하려면 첫 번째 탭의 CLI 명령을 사용하세요.

    - 앱 상단 **`… → 필수 도구 상태`**
    - 설치 폴더 또는 압축을 푼 설치 키트의 **`Setup-Requirements.cmd`**
    - 설치한 앱을 PowerShell에서 실행:

    ```powershell
    Start-Process -FilePath "$env:LOCALAPPDATA\Programs\HWPReview\HWPReview.exe" `
      -ArgumentList '--setup-requirements'
    ```

    모두 준비되어 있으면 다운로드하거나 설치하지 않습니다. .NET·WebView2·Bun/OMP 준비가 필요하면 약관을 확인한 뒤 `약관 확인 후 필수 환경 준비`를 누릅니다. PowerShell 7 또는 글꼴만 누락된 경우에는 준비가 자동으로 시작되며, 설치기나 UAC 창이 표시되면 직접 확인합니다.
  </Tab>
</Tabs>

<Callout type="warn" title="출력 JSON 경로는 항상 새 파일로 지정하세요">
  로컬 드라이브에 있는 절대 경로를 지정하세요. `--check-requirements <path>`는 상대 경로를 받거나 기존 파일을 덮어쓰지 않습니다.
</Callout>
