HWP Editor는 오픈소스 라이선스와 제3자 소프트웨어 경계를 엄격히 구분해 배포합니다.

## 프로젝트 라이선스

- **라이선스**: **`AGPL-3.0-only`** (`LICENSE` 파일 참고)
- 배포 패키지에는 `LICENSE`와 `licenses/`의 제3자 원문 고지가 포함됩니다.
- 상단 **… → 법적 고지**에서 프로젝트 라이선스와 대응 소스 안내를 읽을 수 있습니다. 동봉한 고지 원문은 `licenses/`를 확인하세요.
- [공개 사전 릴리스 v1.0.0-rc.3](https://github.com/mud-the-developer/hwp-editor-public/releases/tag/v1.0.0-rc.3)에서 Windows 설치 ZIP과 `HWPReview-corresponding-source-1.0.0-rc.3.zip`을 같은 조건으로 받을 수 있습니다. [AGPL §6(d)·§10](https://www.gnu.org/licenses/agpl-3.0.html)의 소스 접근 및 수정·재배포 권리가 적용됩니다.

## 배포 패키지에 포함되지 않는 항목

라이선스·보안·개인정보 보호 원칙에 따라 배포 ZIP과 저장소에는 아래 항목을 절대 포함하거나 번들링하지 않습니다.

- 한글(Hancom) 실행 파일, 보안 DLL, 상용/유료 글꼴 바이너리
- Microsoft `.NET 10`, `WebView2`, `PowerShell 7`, `Bun/OMP`, `D2Coding` 설치 바이너리 본체 (설치 시 공식 배포처에서 해시·서명 검증 후 필요 항목만 설치)
- Microsoft Visual C++ v14 재배포 가능 런타임의 개별 DLL과 설치기
- 실제 업무 문서, 직인·서명 이미지, 승인 기록, 인증 토큰, 로컬 개인 설정

## 공개 사전 릴리스 `v1.0.0-rc.3` 검증 범위

- 오프라인 WPF 빌드, EXE 자체시험, 설치 키트와 필수 도구의 읽기 전용 점검을 통과했습니다. 실제 설치·제거를 실행한 점검은 아닙니다.
- 한 Windows x64 PC의 실제 한글에서 새 무서명 합성 문서로 글자 교체(스키마 1), 원래 표 행 높이 보존(스키마 3), 빈 셀 3개 채우기(스키마 4)를 실행했습니다. 같은 EXE로 저장하고 다시 열어 구조와 렌더링을 검사했으며 스키마 3의 `section0` 읽기 순서도 보존했습니다.
- 다른 PC의 설치·실행, 코드 서명, 실제 업무 문서, 모델 호출·기관 결재는 검증 범위가 아닙니다. 상이한 한글 버전이나 문서에서도 같은 결과가 나온다는 보증은 아닙니다.
