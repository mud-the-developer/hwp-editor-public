---
title: 5분 빠른 시작
description: 작업 폴더 열기부터 한글·OMP 실시간 편집, 체크포인트 복원, 최종 내보내기까지 처음 따라 하는 실전 가이드
---

설치를 마쳤다면 아래 6단계를 따라 5분 만에 HWP Editor의 핵심 워크플로를 경험해 볼 수 있습니다.

아직 설치하지 않았다면 [설치 안내](/docs/installation)를 먼저 따르세요. Microsoft Visual C++ v14 **x64 `14.51.36247.0` 이상**이 없다면 [Microsoft 공식 x64 설치기](https://aka.ms/vc14/vc_redist.x64.exe)로 직접 설치해야 합니다. 앱이 이 런타임을 자동으로 내려받거나 설치하지는 않습니다.

<Steps>
  <Step>
    ### 작업 폴더 준비 및 열기 (`Ctrl+O`)

    편집할 `.hwpx` 파일이 들어 있는 폴더를 준비합니다. 원본 문서를 보관하는 공용 폴더나 `example/` 대신 **별도의 작업 폴더**를 사용하는 것이 좋습니다.

    1. 시작 메뉴에서 **HWP Editor**를 실행합니다.
    2. 상단 바의 **`폴더`** 버튼을 클릭하거나 <kbd>Ctrl</kbd>+<kbd>O</kbd>를 눌러 작업 폴더를 선택합니다.
    3. 폴더 안에 `.hwpx` 파일이 있으면 첫 번째 문서가 좌측 미리보기 패널에 자동으로 열립니다.
    4. 빈 폴더에서 바로 시작하고 싶다면 **`… → 새 빈 HWPX 만들기`**(<kbd>Ctrl</kbd>+<kbd>N</kbd>)로 새 `.hwpx` 문서를 만들 수 있습니다.

    <Callout type="info" title="최초 열기 시 자동 불변 백업">
      문서를 처음 여는 순간 `<작업폴더>\.hwpreview\originals\<sha256>.hwpx`에 원본 파일이 1회 자동 백업됩니다. 이후 몇 번을 수정해도 최초 원본 파일은 덮어쓰지 않습니다.
    </Callout>
  </Step>

  <Step>
    ### 오른쪽 OMP 터미널에서 로그인하고 모델 선택

    작업 폴더를 열면 오른쪽에 OMP 터미널이 시작됩니다. 꺼져 있다면 상단 `OMP 시작`을 누르세요.

    1. AI를 처음 사용한다면 터미널에서 `/login`을 입력합니다. 사용할 제공자를 골라 로그인 화면에서 직접 인증합니다. 개인 OMP의 로그인 정보를 앱 전용 프로필로 복사하지 않습니다.
    2. 인증이 끝나면 `/model`로 사용할 모델을 선택합니다. 입력한 요청은 내용을 확인한 다음 <kbd>Enter</kbd>를 눌러 보냅니다.

    AI 없이 사용하는 경우 로그인과 모델 선택을 건너뛰세요. [OMP 첫 사용과 안전한 편집](/docs/guide/omp-workflow#처음-ai를-쓸-때-로그인과-모델-선택)
  </Step>

  <Step>
    ### 문단 더블클릭으로 위치·발췌 전달

    수정하고 싶은 문장을 직접 복사해 설명할 필요가 없습니다.

    1. 좌측 미리보기에서 수정할 **문단을 더블클릭**합니다.
    2. `[report.hwpx · 2쪽 구역 0 문단 5] "선택한 문단 내용..."` 형식의 참조 문자열이 오른쪽 OMP 입력창에 자동으로 붙여넣기 됩니다. (OMP가 꺼져 있으면 Windows 클립보드에 복사됩니다.)
    3. OMP를 사용할 때는 발췌문 뒤에 수정 지시를 덧붙입니다. 모델에 보낼 내용을 확인한 뒤 <kbd>Enter</kbd>를 누르세요.
  </Step>

  <Step>
    ### 한글에서 직접 수정 (`한글에서 열기` + `Ctrl+S`)

    세밀한 표 서식이나 문장 손질은 한글(Hancom)에서 직접 고치는 편이 빠릅니다.

    1. 상단 `한글에서 열기`를 누르면 활성 `.hwpx`가 **Windows에서 연결된 기본 앱**으로 열립니다. 다른 앱이 열리거나 기본 앱이 없으면, 한글을 직접 실행하고 **파일 → 열기**에서 작업 폴더의 같은 `.hwpx`를 선택하세요.
    2. 한글에서 문서를 수정하고 **`Ctrl+S`**로 저장합니다.
    3. HWP Editor가 파일 잠금 해제와 XML 무결성을 확인한 뒤, **현재 보고 있던 쪽·스크롤·배율을 유지한 채** 좌측 미리보기를 즉시 갱신하고 새 체크포인트를 자동 저장합니다.
  </Step>

  <Step>
    ### 서랍(`Ctrl+B`)에서 체크포인트 미리보기 및 복원

    수정이 마음에 들지 않으면 언제든 이전 시점으로 되돌릴 수 있습니다.

    1. <kbd>Ctrl</kbd>+<kbd>B</kbd>를 눌러 좌측 서랍을 엽니다.
    2. 하단 **체크포인트 타임라인**에서 원하는 시점을 클릭하면 미리보기 상단에 배너가 뜨며 해당 시점의 문서를 미리 볼 수 있습니다.
    3. 배너에서 **`이 시점으로 복원`**을 누르면 활성 파일이 해당 체크포인트로 복원되고, **`현재 파일로 돌아가기`**를 누르면 복원 없이 최신 파일 보기로 복귀합니다.
  </Step>

  <Step>
    ### 별도 파일로 내보내기 및 최종 한글 확인

    작업이 끝나면 상단 바의 **`내보내기`** 버튼으로 결과본을 저장합니다.

    - 현재 활성 문서는 `<파일명>-export.hwpx`, 체크포인트 미리보기 상태에서는 `<파일명>-<체크포인트ID>.hwpx`로 저장되며 기존 파일을 덮어쓰지 않습니다.
    - 최종 제출·인쇄 전에는 **한글(Hancom)의 파일 → 열기**에서 내보낸 결과본을 선택해 쪽넘김, 표 테두리, 글꼴, 인쇄 미리보기를 확인하세요.
  </Step>
</Steps>
