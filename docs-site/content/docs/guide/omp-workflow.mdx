우측 패널(기본 42%)은 별도의 커스텀 채팅 래퍼 없이 **Windows ConPTY + xterm.js** 위에서 실제 **`oh-my-pi (OMP)` TUI**를 그대로 실행합니다.

## OMP 세션 라이프사이클

HWP Editor는 경량 라이프사이클 브릿지(`OmpSessionBridge`)를 통해 OMP 세션의 상태와 안전한 종료만 관리하며, 대화·모델 선택·도구 실행 UI는 OMP TUI 본래 인터페이스를 그대로 제공합니다.

- **시작**: 상단 바의 **`OMP 시작`** 또는 **`… → OMP 시작 / 다시 시작`**
  - 작업 폴더가 현재 작업 디렉터리(`cwd`)로 지정되어 실행됩니다.
  - `%LOCALAPPDATA%\HWPReview\Dependencies\Bun-1.4.4-OMP-18.15.0`의 검증된 앱 전용 OMP만 실행합니다. 사용자 `%USERPROFILE%\.bun`으로 대체하지 않습니다.
- **중단 / 정상 종료**: 상단 바의 **`중단`** 또는 **`… → OMP 정상 종료`**
  - OMP가 유휴 상태임을 확인할 수 있어야 정상 종료와 폴더 전환을 진행합니다. 요청이 진행 중이면 먼저 완료될 때까지 기다리거나 터미널에서 중단하세요.
- **터미널 글꼴**: `D2KodingLigature Nerd Font Propo`가 폴백 글꼴로 지정되어 한글과 OMP 상태 표시줄의 아이콘이 깨지지 않습니다.

## 처음 AI를 쓸 때: 로그인과 모델 선택

1. 오른쪽 OMP 터미널에서 `/login`을 입력하고 <kbd>Enter</kbd>를 누릅니다. 목록에서 사용할 제공자를 고르고 화면에 따라 직접 로그인합니다.
2. OMP로 돌아와 `/model`을 실행하고 목록에서 사용할 모델을 선택합니다. 계정에 그 모델을 사용할 권한이 있는지, 비용과 데이터 전송 조건은 무엇인지 확인하세요.
3. 문서 위치·발췌를 붙여넣고 지시문을 작성합니다. 제공자에게 보낼 내용과 수정 대상이 맞는지 확인한 다음 <kbd>Enter</kbd>를 누릅니다. 미리보기·체크포인트·내보내기만 쓸 때는 로그인할 필요가 없습니다.

앱은 개인 OMP 설정이나 로그인 정보를 복사하지 않고 `hwp-report` 프로필을 별도로 사용합니다. Antigravity를 쓰려면 이 프로필에 별도로 설치한 확장과 Agent Client Protocol (ACP) 런타임이 둘 다 필요합니다. 기본 설치 키트에는 포함되지 않습니다.

앱이 실행하는 OMP는 앱 전용 `.gemini` 폴더를 `GEMINI_HOME`으로 사용합니다. 개인 프로필의 토큰이나 설정을 복사하지 마세요. Antigravity를 사용한다면 앱 전용 프로필에서 로그인·모델 선택을 직접 진행하세요. 해당 확장이나 ACP의 호환성 및 로그인 성공을 보장하지 않습니다.

## 문단 더블클릭으로 위치·발췌 전달

좌측 미리보기 패널에서 특정 문단을 **더블클릭**(`PassageDoubleClicked`)하면 HWP Editor가 해당 문단의 정확한 위치와 본문 발췌를 포맷해 OMP로 전달합니다.

### 전달 형식

```text
[<문서이름> · <쪽>쪽 구역 <구역인덱스> 문단 <문단인덱스>] "<발췌 텍스트(최대 240자)>"
```

예시:

```text
[2026-결과보고서.hwpx · 3쪽 구역 0 문단 14] "본 과제는 2단계 실증 시험을 통해 목표 응답 시간을 충족하였으며..."
```

### 동작 방식

| 상태 | 동작 |
| --- | --- |
| OMP 터미널 실행 중 | 브래킷 붙여넣기(bracketed paste)로 OMP 입력창에 즉시 삽입 (자동 전송되지 않으므로 뒤에 지시문을 이어서 입력 가능) |
| OMP 터미널 미실행 | 동일한 참조 문자열을 Windows 클립보드에 자동 복사 |

<Callout type="info" title="왜 자동 전송하지 않나요?">
  문단을 더블클릭했을 때 바로 AI에게 전송되지 않고 입력창에 삽입만 됩니다. 덕분에 여러 문단을 연달아 더블클릭해 인용하거나, 문단 뒤에 "이 문단을 개조식 3줄로 요약해 줘" 같은 구체적인 지시를 덧붙인 뒤 <kbd>Enter</kbd>로 보낼 수 있습니다.
</Callout>

## 작업 폴더 안내 문서(`HWPReview.md`) 활용

작업 폴더 루트에 `HWPReview.md` 같은 간단한 작업 기준 파일을 두면 OMP가 프로젝트의 용어 규칙, 서식 주의 사항, 금지 항목을 일관되게 따르도록 안내할 수 있습니다.

예시 항목:
- 문서의 공식 용어 표기 및 약어 정의 규칙
- 표 열 너비·글꼴 크기 등 건드리지 말아야 할 양식 제약
- 수정 후 반드시 확인해야 할 항목(수치, 날짜, 표 합계 등)

## OMP와 함께 안전하게 편집하는 요령

1. **작은 단위로 요청하기**: 문서 전체를 한 번에 재작성하기보다 문단을 더블클릭해 구역·문단 단위로 수정하면 체크포인트 비교와 복원이 훨씬 쉽습니다.
2. **주요 수정 전 수동 체크포인트 남기기**: 큰 구조 변경 전 `Ctrl+B` 서랍의 **`저장`** 버튼으로 스냅샷을 남겨 두세요.
3. **사실·수치 검증은 직접 확인**: AI가 날짜, 수치, 표 합계, 인용을 임의로 추정하지 않도록 원천 근거를 함께 제시하고, 수정 직후 좌측 미리보기에서 결과를 눈으로 확인하세요.
4. **한글과 교차 편집 시 닫기·다시 열기**: OMP 수정 후에는 이전 한글 창을 다시 저장하지 말고 닫은 뒤 한글의 **파일 → 열기**에서 최신 작업 `.hwpx`를 여세요.
5. **작업 복사본만 지정하기**: 작업 폴더는 OMP의 기본 경로이지 샌드박스가 아닙니다. OMP 도구·셸은 사용자 권한으로 폴더 밖의 파일도 읽거나 쓸 수 있습니다. [보호 경로와 백업](/docs/guide/live-sync#보호-경로-직접-덮어쓰기-차단)을 확인하고 보내거나 수정할 파일을 직접 지정하세요.
