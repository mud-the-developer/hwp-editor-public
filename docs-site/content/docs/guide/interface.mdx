HWP Editor는 불필요한 이중 푸터, 상단 고정 진단 줄, 별도 커스텀 채팅 패널을 모두 제거하고 **문서 미리보기 + OMP 터미널** 2패널에 집중하도록 설계되었습니다.

## 2패널 기본 레이아웃

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ [☰] [폴더] [report.hwpx ▾] [한글에서 열기] [↻ 새로고침] [내보내기]  [●감시중] [OMP] […] │
├──────────────────────────────────────────────┬─────────────────────────────┤
│                                              │                             │
│          좌측 패널 (기본 58%)                  │     우측 패널 (기본 42%)      │
│      HWPX 라이브 미리보기                     │       순수 OMP TUI           │
│      (@rhwp/core 0.8.7 WASM)                 │    (ConPTY + xterm.js)      │
│                                              │                             │
│   * Ctrl+B 입력 시 왼쪽에 260px 서랍 펼침     │   * 문단 더블클릭 시 즉시    │
│   * 가운데 분할선(GridSplitter) 드래그 조절    │     위치·발췌 참조 전달      │
│                                              │                             │
└──────────────────────────────────────────────┴─────────────────────────────┘
```

- **가운데 분할선(`GridSplitter`)**: 좌우 패널 경계를 마우스로 드래그해 미리보기와 OMP 터미널 비율을 자유롭게 조절할 수 있습니다.
- **통일된 디자인 토큰**: WPF 네이티브 셸(`Styles.xaml`), 미리보기 뷰어(`viewer.css`), 터미널(`terminal.css`)이 동일한 색상·간격 토큰을 공유합니다.

## 단일 슬림 상단 바

핵심 작업 버튼은 모두 상단 바 한 줄에 배치되어 있습니다.

| 영역 / 버튼 | 기능 |
| --- | --- |
| **☰ (서랍 토글)** | 260px 왼쪽 서랍 열기/접기 (`Ctrl+B`) |
| **폴더** | 작업 폴더 선택 및 전환 (`Ctrl+O`) |
| **문서 드롭다운** | 작업 폴더의 문서 전환. 개발 소스는 `.hwpx`와 읽기 전용 `.hwp`를 지원하며 공개 `rc.4`는 `.hwpx` 전용 |
| **한글에서 열기** | 현재 활성 `.hwpx`를 Windows 기본 앱에서 열기. 한글이 기본 앱이 아니면 한글의 **파일 → 열기**에서 같은 파일 선택 |
| **↻ 새로고침** | 현재 문서를 디스크에서 강제 재읽기 및 미리보기 갱신 (`F5` / `Ctrl+R`) |
| **내보내기** | 현재 문서(또는 선택된 체크포인트)를 덮어쓰기 없이 별도 `.hwpx`로 저장 |
| **동기화 상태 배지** | 실시간 파일 감시 상태, 최근 자동 갱신 시각, 보호 경로 경고 등 표시 |
| **OMP 상태 / 버튼** | OMP 세션 상태 확인 및 `OMP 시작` / `중단` 제어 |
| **`…` 오버플로 메뉴** | 보조 작업 및 진단 기능 모음 |

### `…` 오버플로 메뉴 항목

| 메뉴 항목 | 설명 |
| --- | --- |
| **새 빈 HWPX 만들기 (`Ctrl+N`)** | 작업 폴더에 표준 구조의 새 빈 `.hwpx` 파일 생성 |
| **다른 문서 저장 시 자동 전환** (개발 소스) | 기본 켜짐. 끄면 현재 문서의 저장만 화면을 갱신하고 다른 문서는 목록에서 선택 |
| **수동 체크포인트 저장** | 현재 파일 상태를 즉시 `.hwpreview/history/`에 스냅샷 저장 |
| **OMP 시작 / 다시 시작** | 현재 작업 폴더에서 OMP 세션을 시작하거나 깨끗하게 재시작 |
| **OMP 정상 종료** | 실행 중인 OMP 세션을 안전하게 종료 (폴더 전환·앱 종료 전 정리) |
| **기존 HWP 도구** | `.hwp` 검토용 별도 창 열기. OMP 세션이 실행 중이면 먼저 **OMP 정상 종료** |
| **필수 도구 상태** | 누락 항목을 설치할 수 있는 준비 창 열기. 설치 없이 상태만 보려면 [CLI 점검](/docs/installation/prerequisites#필수-도구-상태-점검-및-재설치-방법) 사용 |
| **법적 고지** | `AGPL-3.0-only` 라이선스와 대응 소스 안내 확인. 제3자 원문 고지는 키트의 `licenses/`에 있습니다. |

### 기존 HWP 검토

이 창은 기본 HWPX 미리보기와 별개입니다. 새 검토 자료를 준비하고 수정안을 적용하려면 호환되는 한글과 승인된 오토메이션 보안 모듈이 이미 설정되어 있어야 합니다. 앱은 한글이나 보안 DLL을 설치하지 않습니다.

1. `… → 기존 HWP 도구`에서 **HWP 문서 선택 → 원본 확인 시작**으로 작업용 사본과 검토 자료를 준비합니다. 이전에 준비한 검토 자료는 **작업 폴더 열기**로 불러옵니다.
2. **글자 교체 · 페이지 메모**, **표 행 높이 보존**, **무서명 양식 빈 셀 채우기** 중 맞는 모드를 선택하고 **검토 시작**을 누릅니다. 페이지와 대상 위치를 확인하고 **수정안 저장 · 승인 아님**으로 저장합니다.
3. **승인 · 적용** 탭에서 대상과 보존 조건을 읽고 **표시된 수정안과 모든 대상 위치를 확인했습니다**를 체크한 뒤 **이 수정안만 승인**을 누릅니다. 실제 반영은 **승인한 수정안 적용…**에서 별도로 확인합니다. 결과를 확인한 뒤 **이력 · 내보내기**에서 검증된 HWP 또는 PDF를 새 파일로 저장합니다.

기존 직인·서명이 보존돼도 승인이나 기관 제출 권한을 뜻하지 않습니다. [한글 이용 조건과 검증 범위](/docs/developer/licensing-and-boundaries)를 확인하세요.

## 왼쪽 접힘 서랍 (`Ctrl+B`)

기본 상태에서는 화면 공간을 넓게 쓰기 위해 접혀 있으며, <kbd>Ctrl</kbd>+<kbd>B</kbd> 또는 상단 왼쪽 토글 버튼으로 260px 폭으로 펼칩니다.

1. **작업 폴더 문서 목록**
   - 작업 폴더 내 `.hwpx` 파일 목록을 보여주고 클릭 한 번으로 문서를 전환합니다.
   - 상단의 **`+ 새 HWPX`** 버튼으로 새 빈 문서를 바로 생성할 수 있습니다.
2. **체크포인트 타임라인**
   - 상단의 **`저장`** 버튼으로 수동 체크포인트를 즉시 남길 수 있습니다.
   - 한글 또는 OMP가 문서를 저장할 때마다 자동 누적된 체크포인트가 시간순으로 표시됩니다.
   - 항목을 클릭하면 현재 작업 파일을 덮어쓰지 않은 채 해당 시점을 미리볼 수 있습니다.

## 키보드 단축키 전체 표

| 단축키 | 동작 | 비고 |
| --- | --- | --- |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | 왼쪽 서랍(문서 목록 · 체크포인트) 열기 / 닫기 | 기본 접힘 |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | 작업 폴더 열기 / 변경 | 활성 OMP 세션 정리 후 전환 |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | 새 빈 `.hwpx` 문서 만들기 | 작업 폴더에 새 파일 생성 |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> 또는 <kbd>F5</kbd> | 활성 문서 미리보기 수동 새로고침 | 디스크에서 다시 읽어 갱신 |
| **문단 더블클릭** (미리보기) | 문단 위치·발췌를 OMP 터미널로 전달 | OMP 미실행 시 클립보드 복사 |
