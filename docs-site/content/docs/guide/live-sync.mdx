활성 `.hwpx`를 저장하면 미리보기가 갱신됩니다. **… → 다른 문서 저장 시 자동 전환**이 있는 버전에서는 작업 폴더나 하위 폴더에서 OMP가 새로 만든 문서와 다른 이름으로 저장한 문서도 표시합니다. 현재 파일만 보려면 이 옵션을 끄세요. 체크포인트를 비교하는 중에는 화면이 고정됩니다.

## 전체 실시간 동기화 파이프라인

```text
한글 Ctrl+S 또는 OMP 수정
   │
   ▼
작업 폴더 FileSystemWatcher (Changed / Created / Renamed / Deleted)
   │  └─ 400ms 디바운스 (연속 쓰기·임시파일 교체 묶음 처리)
   ▼
파일 잠금 해제 대기 (최대 12회 × 120ms 재시도)
   │
   ▼
무결성 검증
   ├─ 일반 파일 & 비하드링크 & 크기 1B ~ 64MiB 확인
   ├─ HWPX: ZIP 구성원과 Contents/section0.xml 검증
   ├─ HWP5: OLE 헤더·본문 스트림·서명/보호 여부 확인
   └─ 보안 차단: <!DOCTYPE / <!ENTITY 포함 XML 거부
   │
   ▼
SHA-256 비교 (실제 바이트 변경이 있을 때만 진행)
   │
   ├─▶ .hwpreview/history/<hash16>/ 자동 체크포인트 저장
   └─▶ 같은 체크포인트 바이트를 상주 WebView2에 표시 (같은 문서면 쪽·스크롤·배율 유지)
```

<Callout type="info" title="화면 깜빡임 없는 in-place 갱신">
  문서가 바뀔 때마다 WebView2 인스턴스를 파괴하고 다시 생성하지 않습니다. 상주 중인 WebView2에 새 문서 바이트만 전달해 **현재 보고 있는 쪽 번호, 스크롤 위치, 확대 배율을 그대로 유지**한 채 화면을 갱신합니다.
</Callout>

## 최초 1회 불변 원본 백업

문서를 처음 열 때 검증된 바이트를 원래 확장자(`.hwpx` 또는 개발 소스의 `.hwp`)로 보존합니다. HWPX의 예:

```text
<작업폴더>\.hwpreview\originals\<sha256>.hwpx
```

- 동일한 SHA-256 원본 백업이 이미 존재하면 **절대 덮어쓰지 않고** 기존 백업 무결성만 검증합니다.
- 편집 도중 실수가 생기더라도 최초 원본 파일은 `.hwpreview/originals/`에 항상 그대로 남아 있습니다.

## 보호 경로 직접 덮어쓰기 차단

HWP Editor는 아래 경로를 활성 작업 문서로 열거나 복원하지 않습니다. 폴더명과 파일명의 대소문자는 구분하지 않습니다.

- `example/`, `.hwpreview/`, `.git/` 아래의 파일
- 파일명이 정확히 `baseline.hwpx`, `baseline.hwp`, `baseline.pdf`, `source.hwpx`인 파일. `baseline-v2.hwpx`처럼 이름이 다른 파일은 이름만으로 차단되지 않습니다.
- 선택한 작업 폴더 범위 안에서 앱 관리 프로젝트 마커(`report-project.json`)가 있는 폴더 아래의 파일

<Callout type="warn" title="원본 예시 폴더에서 바로 편집하지 마세요">
  보호된 `.hwpx`는 별도의 작업 폴더에 `report-edit.hwpx`처럼 보호 목록에 없는 이름으로 복사하세요. 이 차단은 HWP Editor의 작업 경로에만 적용됩니다. OMP의 기본 도구·셸이나 외부 편집기는 Windows 사용자 권한으로 작업 폴더 밖에도 접근하므로, 원본·백업을 직접 수정하도록 요청하지 마세요.
</Callout>

## 체크포인트 타임라인과 복원

문서별 자동·수동 체크포인트는 작업 폴더 내부의 아래 경로에 문서별 상대 경로 해시(앞 16자리) 폴더로 구분 저장됩니다.

```text
<작업폴더>\.hwpreview\history\<sha256(normcase(relpath))[:16]>\
```

### 체크포인트 사용 방법

1. <kbd>Ctrl</kbd>+<kbd>B</kbd>를 눌러 서랍을 엽니다.
2. **수동 저장**: 중요한 분기점 앞에서 체크포인트 영역 상단의 **`저장`** 버튼(또는 `… → 수동 체크포인트 저장`)을 누릅니다.
3. **시점 미리보기**: 타임라인 목록에서 과거 항목을 클릭합니다.
   - 이 단계에서는 **현재 작업 파일을 덮어쓰지 않습니다.**
   - 좌측 미리보기 상단에 체크포인트 미리보기 배너가 나타납니다.
4. **배너 액션 선택**:
   - **`이 시점으로 복원`**: 활성 `.hwpx` 파일을 선택한 체크포인트 내용으로 복원합니다. (복원 전 현재 상태도 안전하게 추적됩니다.)
   - **`현재 파일로 돌아가기`** / **`닫기`**: 복원하지 않고 최신 디스크 파일 미리보기로 돌아갑니다.
5. **체크포인트만 따로 내보내기**: 체크포인트를 미리보는 상태에서 상단 **`내보내기`**를 누르면 현재 파일을 건드리지 않고 `<파일명>-<체크포인트ID>.hwpx`로 별도 저장합니다.

<Callout type="warn" title="한글과 OMP가 동시에 같은 파일을 저장할 때 주의">
  OMP가 같은 `.hwpx`를 수정해도 한글에 이미 열린 문서는 자동으로 새로고침되지 않습니다. 이전 창을 다시 저장하면 OMP의 수정이 덮일 수 있습니다. 한글에서 작업을 이어갈 때는 기존 창을 닫고 한글의 **파일 → 열기**에서 작업 폴더의 최신 `.hwpx`를 여세요.
</Callout>
