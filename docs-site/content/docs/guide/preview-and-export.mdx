HWP Editor의 좌측 미리보기는 외부 서버로 문서를 업로드하지 않고, PC 내부의 **WebView2 + `@rhwp/core 0.8.7` WASM 엔진**으로 `.hwpx`를 직접 렌더링합니다.

## 로컬 미리보기 특징

- **완전한 오프라인 렌더링**: 미리보기 표시를 위해 문서 내용을 외부로 전송하지 않습니다.
- **in-place 실시간 갱신**: 파일이 바뀌어도 WebView2를 새로 띄우지 않고 메모리에서 문서만 교체해 **현재 쪽, 스크롤 위치, 배율**을 유지합니다.
- **문단 선택 및 더블클릭**: 문단을 더블클릭해 쪽·구역·문단 번호와 본문 발췌(최대 240자)를 OMP 터미널이나 클립보드로 전달합니다.
- **체크포인트 미리보기 모드**: 서랍에서 과거 체크포인트를 선택하면 활성 파일을 변경하지 않고 과거 시점 화면을 그대로 확인합니다.

## 내보내기(`내보내기`) 규칙

상단 바의 **`내보내기`** 버튼은 현재 보고 있는 문서를 **원본이나 활성 파일을 덮어쓰지 않고** 새 파일로 저장합니다.

| 현재 상태 | 기본 제안 파일명 | 동작 |
| --- | --- | --- |
| 활성 작업 파일 보기 중 | `<원본이름>-export.hwpx` | 작업 폴더(또는 선택한 위치)에 복사 저장 |
| 체크포인트 미리보기 중 | `<원본이름>-<체크포인트ID>.hwpx` | 선택한 과거 시점을 새 파일로 저장 |

- 대상 경로에 같은 이름의 파일이 이미 있으면 임의로 덮어쓰지 않고 안전하게 충돌을 방지합니다.

## 구형 `.hwp` 파일 사용 방법

`.hwp`를 원본 형식 그대로 검토하려면 [기존 HWP 도구](/docs/guide/interface#기존-hwp-검토)를 사용하세요. 기본 HWPX 창에서 실시간 미리보기와 체크포인트를 쓰려면 다음 순서로 변환하세요.

1. 한글(Hancom)에서 `.hwp` 파일을 엽니다.
2. **파일 → 다른 이름으로 저장하기**를 선택합니다.
3. 파일 형식을 **한글 표준 문서 (`*.hwpx`)**로 지정해 작업 폴더에 저장합니다.
4. HWP Editor에서 해당 작업 폴더를 열어 편집·미리보기·체크포인트를 사용합니다.

## 내장 미리보기의 한계와 최종 확인 원칙

<Callout type="warn" title="최종 제출·인쇄 전 반드시 한글(Hancom)에서 확인하세요">
  `@rhwp/core` WASM 렌더러는 빠른 편집 확인과 위치 파악을 위한 **근사 미리보기**입니다. 다음과 같은 세부 조판 요소는 실제 한글(Hancom) 프로그램과 미세하게 다를 수 있습니다.
</Callout>

- 한글 전용 유료 글꼴 또는 시스템에 없는 글꼴의 대체 렌더링으로 인한 줄바꿈·쪽넘김 차이
- 복잡한 다단, 겹친 도형·그리기 개체, 수식, 머리말/꼬리말·각주/미주 경계
- 보안·전자서명·직인 이미지가 포함된 공문서 양식

내보낸 결과본을 한글의 **파일 → 열기**에서 직접 선택해 인쇄 미리보기를 확인하세요. HWP Editor의 `한글에서 열기`는 내보낸 결과본이 아니라 활성 작업 파일을 Windows 기본 앱으로 엽니다.

### 공식 문서·직인 문서 주의 사항

- 문서 안에 기존 직인/서명 이미지가 그대로 남아 있더라도, 수정된 문서에 대한 승인 효력이 자동으로 승계되지 않습니다.
- 실제 제출용 문서는 반드시 **승인된 무서명 양식**을 기준으로 작업하고, 최종 단계에서 **한글(Hancom)**에서 쪽맞춤과 인쇄 미리보기를 검증한 뒤 정식 결재·날인 절차를 거치세요.
