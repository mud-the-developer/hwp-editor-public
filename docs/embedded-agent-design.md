# 내장 Agent와 GUI의 경계

## 구성

현재 기본 앱은 Windows WPF의 문서 트리·HWPX 쪽 미리보기·OMP 대화/수정 메모입니다. 실제 터미널은 ConPTY와 로컬 xterm·WebView2로 같은 OMP 세션에 연결됩니다. 별도 문서 편집 agent나 독립 승인 서버를 만들지 않습니다. 이 문서는 현재 소스 설계이며 해당 공개 후보의 실행 검증 기록이 아닙니다.

기본 OMP는 앱 전용 HOME·프로필과 선택한 작업 폴더 cwd를 사용합니다. 사용자는 직접 로그인·모델을 설정합니다. 앱은 개인 인증을 복사하거나 로그인 성공·무료 사용을 탐색 결과로 단정하지 않습니다. 기본 OMP 도구·셸은 그대로이며 사용자의 OS 권한으로 실행됩니다. 프로젝트 밖 접근도 가능하므로 sandbox나 읽기 전용 agent라고 부르지 않습니다. `HWPReview.md`는 기본 프롬프트에 덧붙이는 편집 가능한 안내입니다.

## 데이터 흐름

1. 사용자가 선택 본문·메모·자료를 로컬에서 확인합니다. 목록·미리보기·문서 속 경로만으로 모델에 첨부하지 않습니다.
2. 일반 대화와 명시적 수정안 요청을 구분해 같은 세션으로 보냅니다. 실제 UTF-8 전송 크기를 검사하며 초과 문맥을 자동 절삭하지 않습니다.
3. 앱 소유 extension과 현재 사용자 named pipe가 실행 식별자·token·세션·cwd·순서·크기를 검사해 공개 assistant 응답을 전달합니다. 비공개 추론은 제안으로 사용하지 않습니다.
4. 현재 요청·문맥·세션이 정상 완료하고 실제 유휴인 경우에만 닫힌 제안을 검사합니다. 전송 확인·대기 메시지는 완료가 아닙니다. 동시 TUI 입력·상태 불명확에서는 자동 연결을 해제합니다.
5. 사용자의 별도 수정본 생성 클릭으로 기존 GUI 권한 경로와 컴파일러가 새 미승인 파일을 만듭니다. 모델을 다시 호출하지 않습니다.
6. 사람이 검토한 정확한 바이트의 채택만 별도 기록합니다. 변경·후속 요청·외부 수정은 새 미채택 버전입니다.

## 재사용하는 권한 경로

기존 `TemplateHandler`와 report project/harness API가 입력·범위·해시·revision·권한·결과를 검사합니다. 문맥 조회·제안 수신은 생성 권한이 아닙니다. source/artifact 미리보기는 검증한 바이트만 받는 별도 읽기 전용 뷰이며 OMP·실행·승인 API가 없습니다.

고급 SDK는 선택 문구·상태 snapshot과 명시적 제안 도구만 사용하며 파일·셸·승인·실행을 제공하지 않습니다. 승인 작업 요청 카드는 실제 작업 실행이 아닙니다. 기존 controller가 현재 계획·승인·잠금·소유권을 재검사한 뒤 GUI의 별도 적용 확인을 거칩니다. 이 SDK 경계를 기본 OMP 셸의 접근 제한으로 설명하지 않습니다.

## 보존과 종료

원본·기준·불변 버전·실패·부분 출력·lease를 보존합니다. GUI의 해시/권한 검사는 외부 셸 쓰기를 막는 OS 경계가 아닙니다. 승인 기록의 직접 생성·수정은 금지합니다. 소스/frozen·다른 EXE·기기·사용자의 권한을 이관하지 않습니다.

취소는 요청이지 완료가 아닙니다. 실제 유휴·소유 프로세스 정상 종료를 기다리며 실행 중·불명확한 상태에서는 문서 전환·생성·닫기를 차단합니다. 자동 재연결·재전송·cache 수리·다른 모델 fallback·강제 종료는 하지 않습니다. OMP 자체의 모델 재시도·요약·도구 확인은 사용자 설정을 따릅니다.

## 검증 경계

합성 이벤트·모의 SDK/model/Native·loopback 검사, frozen GUI·터미널·렌더러 검사, 실제 모델·한글·다른 PC·Windows 설치/제거 수명주기는 별개입니다. 생성 동의·채택·실제 한글 검수·Native 적용·제출·배포도 서로 다른 권한입니다. 화면의 진행·사용량은 실제 제공된 관찰만 표시하고 인증·비공개 추론·원시 민감 로그를 공개하지 않습니다.
