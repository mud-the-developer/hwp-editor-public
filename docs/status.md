# 현재 상태

## 공개 소스와 제작 상태

- 저장소: <https://github.com/mud-the-developer/hwp-editor-public>
- 현재 소스 제작 버전: `1.0.0`.
- WPF 기반 HWPX 작성·검토 소스와 기존 고급 HWP 도구를 포함합니다.
- 공개 소스 URL·문서·고지가 바뀐 소스에는 새 후보 빌드가 필요합니다. 다른 소스의 기존 EXE·ZIP을 공개판과 짝지을 수 없습니다.
- 초안 사전 릴리스는 정식 배포가 아닙니다. 공개 소스의 존재와 바이너리 게시·시험·법적 재배포 준비는 별개입니다.

## 제공하는 소스 기능

작업 폴더와 문서 선택, 빈 HWPX 작성, 연속 쪽 미리보기, 기본 OMP 세션, 메모·선택 자료, 수정안 요청, 미승인 수정본 생성, 버전 이력, 검토용 사본과 외부 수정본 가져오기, 정확한 파일 채택을 연결합니다. 원본·기준 파일은 보존합니다. 외부 셸은 사용자 권한으로 실행되며 GUI 밖 쓰기를 격리하지 않습니다.

현재 사용자 설치·제거 스크립트와 필수 도구 준비 경로가 있습니다. 이는 Windows의 모든 실제 수명주기에서 검증되었다는 뜻이 아닙니다. 설치 영수증 계약은 `hwp-user-install-receipt-v2`입니다.

## 검증 주장의 경계

이 문서는 기능·검증 경계의 안내이며 현재 후보의 시험 영수증이 아닙니다. 실제 수행한 검사는 해당 릴리스의 정확한 commit·EXE·검증 manifest로 확인합니다. 과거 검사 수치나 다른 후보의 결과는 승계하지 않으며, 별도 증거가 없는 항목은 **미검증**입니다.

- 합성·모의 SDK/모델/Native 검사는 실제 모델·한글의 양성 검증이 아닙니다.
- frozen EXE의 정확한 UI·터미널·렌더러 동작은 소스 검사와 별개입니다.
- 다른 PC·깨끗한 PC 검증과 실제 Windows 설치/제거·UAC·취소·재부팅·충돌 수명주기를 완료했다고 주장하지 않습니다.
- 코드 서명 완료·전체 재배포 적합성·한글 최종 배치·제출 승인을 주장하지 않습니다.
- 배포 한계 표시는 `redistribution_ready=false`, 서명 미완료, 다른 PC 미검증 상태를 정직하게 유지해야 합니다.

## 유지되는 제한

생성 동의, 정확한 파일 채택, 실제 한글 검수, Native 적용, 제출은 각각 별도입니다. schema1/3/4의 strict 정책, schema2와 generic Native 차단, 외부 binding·입력/출력 해시·소유 인스턴스 검사는 공개판에서도 완화하지 않습니다. 실패·timeout·불명확한 정리에서 멈추며 자동 재시도·cache 수리·강제 종료로 통과시키지 않습니다.
