# HWP Editor 사용법

공개 `1.0.0` 소스의 기본 화면은 왼쪽 **HWPX 라이브 미리보기**, 오른쪽 **oh-my-pi (OMP) 터미널**입니다. `.hwp` 문서를 검토해 새 HWP/PDF를 내보내는 기능은 별도 **기존 HWP 도구**에 있습니다. [설치와 필수 도구](desktop-app.md)

## HWPX 작업 폴더

1. **폴더** 또는 `Ctrl+O`로 작업 폴더를 엽니다. 상단 문서 목록에서 작업용 `.hwpx`를 선택하거나 `Ctrl+N`으로 빈 문서를 만듭니다.
2. 최초 원본은 `.hwpreview/originals/`에 보존됩니다. 한글이나 OMP가 활성 파일을 저장하면 미리보기와 `.hwpreview/history/` 체크포인트가 갱신됩니다. `example/` 등 보호 경로는 덮어쓰지 않습니다.
3. **한글에서 열기**는 활성 파일을 Windows 기본 앱으로 엽니다. 다른 앱이 열리면 한글의 **파일 → 열기**에서 같은 파일을 고르세요. OMP가 파일을 수정한 뒤에는 예전 한글 창을 다시 저장하지 말고 파일을 다시 엽니다.
4. `Ctrl+B` 서랍에서 문서 전환, 체크포인트 미리보기·복원이 가능합니다. **내보내기**로 별도 파일을 저장하고 글꼴·쪽맞춤·인쇄 미리보기를 한글에서 확인하세요. 로컬 미리보기는 최종 조판 검수를 대신하지 않습니다.

### OMP 터미널

AI를 사용할 때만 오른쪽에서 `/login`과 `/model`을 사용합니다. 본문을 더블클릭하면 위치와 발췌만 터미널에 붙여넣거나 클립보드에 복사합니다. 내용을 확인한 뒤 직접 전송하세요. OMP는 `HWPReview.md`를 안내로 쓰지만 기본 셸을 샌드박스로 제한하지 않습니다. 앱은 개인 인증을 복사하지 않으며 선택적인 확장·공급자 런타임은 동봉하지 않습니다.

폴더를 전환할 때는 기존 세션이 유휴 상태이며 정상 종료됐는지 확인합니다. 요청 중단은 완료가 아니므로 작업이 끝나기 전에 창을 강제 종료하지 마세요.

## 기존 HWP 도구

**… → OMP 정상 종료** 뒤 **… → 기존 HWP 도구**를 선택합니다. 소스에서는 `start-review.cmd`, 패키지에서는 `HWPReview.exe --legacy-desktop`으로도 열 수 있습니다. 브라우저를 열지 않습니다.

### 검토 자료와 수정안 준비

- **HWP 문서 선택 → 원본 확인 시작**으로 작업 사본과 기준 PDF·HWPX를 준비합니다. **작업 폴더 열기**로 검토를 이어갈 수 있습니다. 암호·배포 보호·전자서명·미지원 구조는 우회하지 않으며, 원본은 덮어쓰지 않습니다.
- 호환 한글, 유효한 등록 보안모듈, 준비된 COM 래퍼가 필요합니다. 호환 x86 한글의 누락 보안모듈은 [필수 도구 준비](desktop-app.md#필수-도구-준비)에서 명시적 동의 후 공식 파일로 준비합니다. 검토·적용 중에는 설치하거나 수리하지 않습니다.
- **글자 교체 · 페이지 메모**(스키마 1), **표 행 높이 보존**(3), **무서명 양식 빈 셀 채우기**(4)에서 지원 범위만 고릅니다. 스키마 2, 임의 한글 쓰기, 병합·서명·기존 값 등 지원하지 않는 셀은 차단합니다.
- 빈 셀 모드는 작업의 `_review/fill-input.json`에서 `bindings`와 `record`를 읽습니다. [필드 지도·값·근거 작성법](form-draft-and-safety-lint.md#1-빈-양식-지도)에 따라 그 작업의 `baseline.hwpx`에 맞는 자료를 준비하고 실제 원래 빈 셀 위치를 화면에서 고릅니다. 승인 파일이나 기준 해시는 직접 수정하지 않습니다.

### 저장, 승인, 적용과 내보내기

1. **검토 시작 → 수정안 작성**에서 원본 쪽·수정 대상을 보고 **초안에 담기**를 누릅니다. **수정안 저장 · 승인 아님**으로 저장합니다. 쪽 메모는 승인과 별개입니다.
2. **승인 · 적용**에서 모든 대상 위치·변경 문구·보존 조건을 확인하고 체크한 뒤 **이 수정안만 승인**을 누릅니다. 승인만으로 한글을 실행하지 않습니다.
3. **승인한 수정안 적용…**에서 별도로 확인합니다. 한글 저장·재개방이 끝날 때까지 기다리세요. 오류가 나면 첫 실패와 자료를 보존하며 잠금 삭제·자동 재실행·강제 종료로 우회하지 않습니다.
4. **이력 · 내보내기**에서 기준 쪽·결과·차이를 확인하고 검증된 HWP/PDF를 새 파일로 저장합니다. 저장·재개방 통과는 제출이나 결재 승인이 아닙니다.
