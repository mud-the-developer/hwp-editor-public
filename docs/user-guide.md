# HWPX 작성·검토 사용법

## 시작과 문서 선택

[설치와 필수 도구](desktop-app.md)를 먼저 확인하세요. 현재 제작 소스는 `1.0.0`이며 공개 소스와 정확히 일치하는 새 배포물만 사용합니다. 기본 화면은 왼쪽 문서·수정본 트리 / 가운데 HWPX 연속 쪽 / 오른쪽 같은 OMP 세션의 대화·수정 메모입니다.

1. **작업 폴더 / Ctrl+O**로 일반 폴더나 빈 폴더를 엽니다. 목록을 보는 것만으로 모델에 보내지 않습니다.
2. 트리의 HWPX를 고르거나 **Ctrl+Shift+O**로 외부 문서를 직접 선택합니다. **＋ / 새 HWPX 만들기 / Ctrl+N**은 작업 폴더 안의 새 파일명에 실제 빈 HWPX를 만듭니다. 기존 파일은 덮어쓰지 않습니다.
3. **OMP 로그인으로 시작**에서 `/login`과 모델을 직접 설정하고 **대화 화면으로**로 돌아옵니다. 문서 없이 대화도 가능합니다. 기존 개인 인증을 복사하지 않습니다.
4. 프로젝트는 선택 폴더의 `.hwpreview/Projects`에 보존됩니다. 같은 문서는 검증한 기존 작업을 재사용하며 변경·중단·불명확한 작업을 새 캡처로 조용히 덮어쓰지 않습니다.

폴더가 실제 OMP 작업 경로입니다. 폴더 변경은 기존 세션의 유휴·정상 종료를 확인한 뒤 연결합니다. OMP 기본 도구·셸은 사용자 권한으로 프로젝트 밖에도 접근합니다. 앱은 sandbox가 아니며 `HWPReview.md`는 안내일 뿐입니다. 기존 안내·사용자 수정은 덮어쓰지 않습니다.

## 메모·자료·수정 요청

가운데 본문을 두 번 클릭하면 현재 파일 해시와 위치를 확인한 수정 메모를 만듭니다. 빈 곳·모호한 위치·미지원 표 셀 등을 가까운 본문으로 추측하지 않습니다. 메모는 편집·삭제할 수 있고 미전송 메모가 있으면 종료 전 알립니다.

메모나 추가 요청에서 `@`로 파일을 검색하고 방향키·Tab·Enter 또는 클릭으로 고릅니다. **폴더 연결 / 파일 선택**으로 자료 위치를 직접 지정합니다. 문서에 적힌 경로를 자동 첨부하지 않습니다. 직접 고른 UTF-8 텍스트·코드 또는 HWPX 본문 발췌만 대기 자료가 됩니다. 선택·미리보기는 전송이 아닙니다. 이미 보낸 자료는 나중에 공유를 해제해도 회수할 수 없습니다.

- **보내기 / Ctrl+Enter**: 일반 대화. 문서 생성 권한이 아닙니다.
- **수정안 요청**: 선택 본문·자료·메모·비용을 확인해 같은 세션에 명시적으로 전송합니다.
- 검사된 제안 아래 **수정본 만들기**: 원본을 보존한 새 미승인 HWPX 생성의 별도 동의입니다. 제안 도착·메모·채팅 동의만으로 생성하지 않습니다.

요청은 최대 16,000자, 공유 문맥은 32 KiB이며 실제 전송 요청도 UTF-8 32 KiB 이하여야 합니다. 자료는 텍스트/코드 원본 512 KiB 또는 HWPX 원본 64 MiB, 모델용 스냅샷 64 KiB 이내입니다. 전체 제한을 넘으면 자동으로 자르지 않고 전송을 막습니다. HWPX 발췌는 배치·그림·OCR이 아닙니다.

미지원 표·그림·제어 개체·혼합 서식은 버리거나 평문으로 바꾸지 않습니다. 범위를 다시 확인하거나 [준비 원고 경로](template-review-draft.md)를 사용하세요.

## 검토·채택·내보내기

새 수정본은 트리와 가운데에 표시됩니다. 과거 원본·수정본도 선택할 수 있습니다. 문서 상단 **⋯**에서 검토 사본 열기, 저장 사본/외부 수정 가져오기, 정확한 파일 채택, 내보내기, 변경 내용을 사용합니다.

검토용 사본을 외부에서 저장했다면 가져와 새 버전으로 검토합니다. 변경된 사본이 남아 있으면 이전 기준 파일을 채택하지 않습니다. 후속 요청·외부 수정은 새 미채택 버전이며 파일 변경은 이전 채택을 승계하지 않습니다. 채택은 모델을 다시 호출하거나 파일을 재생성하지 않습니다. 원본·기준 파일·이력은 불변입니다.

로컬 미리보기는 `@rhwp/core 0.8.7`로 검증한 HWPX 전체 바이트를 렌더링합니다. 읽기 전용이며 원격 탐색·글꼴·활성 코드 실행 기능이 없습니다. 글꼴·미지원 요소 때문에 한글의 실제 쪽 배치와 다를 수 있습니다. 미리보기나 추출 텍스트만으로 최종 검수가 끝난 것은 아닙니다.

**생성 동의 → 사람 검토 → 정확한 파일 채택**과 **실제 한글 검수·Native 적용·제출 승인**은 각각 별개입니다. 직인·서명이 보존되었다고 수정 문서가 승인된 것은 아닙니다.

## 실패·중단·종료

**상태 다시 읽기**는 기존 상태만 읽으며 모델 요청·생성·채택을 재전송하지 않습니다. 실행 중·상태 불명확에서는 문서 생성·닫기·전환을 차단합니다. **현재 요청 중단**은 취소 요청이지 완료가 아닙니다. 알려진 유휴에서 **OMP 정상 종료** 또는 창 닫기로 실제 종료를 기다립니다. 강제 종료·잠금 삭제·cache 수리·다른 모델 fallback으로 우회하지 않습니다. OMP 자체의 모델 재시도·요약·도구 확인은 사용자 OMP 설정에 따릅니다.

## 기존 HWP 고급 도구

앱 메뉴의 **기존 HWP 도구**는 별도 창이며 기본 HWPX 흐름의 검증 완료 기능이 아닙니다. 문서 선택 → 새 작업 사본 → 원본 확인의 별도 허용 → 검토 → 정확한 수정안 승인 → 별도 적용 순서를 따릅니다. manifest·승인 기록은 엔진/UI만 작성하며 사용자가 만들거나 조작하지 않습니다.

설치·허가된 한글, 승인 등록 보안 모듈, 준비된 COM wrapper cache가 필요합니다. 앱은 이를 설치·등록·수리하지 않습니다. 소유 인스턴스에서 사본만 다루고 기존 사용자 한글 창에 연결하지 않습니다. strict schema1/3/4의 현재 가용 범위만 허용하며 schema2·미지원 읽기 순서·복잡한 표·generic Native는 차단합니다. 실패·timeout·불명확한 정리에서 멈추고 잠금·부분 출력·첫 실패 증거를 보존합니다.
