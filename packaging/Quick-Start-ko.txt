HWP Editor 간단 사용법

1. ZIP을 새 폴더에 모두 풀고 Install-HWPReview.cmd를 실행합니다.
   약관·관리자 확인은 직접 진행합니다.
2. 시작 메뉴에서 HWP Editor를 엽니다.
   왼쪽은 HWPX 라이브 미리보기, 오른쪽은 oh-my-pi (OMP) 터미널입니다.
3. 상단 바에서 작업 폴더(Ctrl+O)와 HWPX 문서를 고르거나 Ctrl+N으로 새 HWPX를 만듭니다.
   Ctrl+B 서랍에서 작업 폴더의 문서 전환과 자동 저장 체크포인트 복원을 할 수 있습니다.
4. 처음 열 때 .hwpreview/originals/에 불변 원본이 1회 백업됩니다.
   OMP를 처음 쓰려면 오른쪽 터미널에서 /login으로 직접 로그인하고 /model로 모델을 선택합니다.
   [한글에서 열기]는 활성 .hwpx를 Windows 기본 앱으로 엽니다. 한글이 기본 앱이 아니면 한글의 [파일 → 열기]에서 같은 .hwpx를 선택합니다.
   OMP나 한글에서 활성 문서를 수정·저장(Ctrl+S)하면
   왼쪽 미리보기가 현재 쪽·배율을 유지한 채 자동 갱신되고 체크포인트가 쌓입니다.
5. 문서 문단을 더블클릭하면 위치·발췌 참조가 오른쪽 OMP 터미널로 전달됩니다.
6. 상단 [내보내기]로 별도 파일을 저장하고, 해당 결과본을 한글의 [파일 → 열기]에서 열어 최종 서식을 확인합니다.

example/ 등 보호 경로 직접 덮어쓰기는 차단합니다.
