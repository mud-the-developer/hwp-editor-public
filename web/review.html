      탭을 닫기 전 복구용 초안 저장을 누르면 위치·미저장 문구를 작업 폴더에 보관합니다. 메모/수정안 저장·승인·적용과 다르며 자동 저장/자동 복구하지 않습니다. 보관 내용은 로컬 평문입니다.
      1초 대기 후 로컬 평문 보관합니다. 승인/적용은 자동화하지 않으며 충돌/실패 시 꺼지고 재시도하지 않습니다.
      

      메모 처리 · 근거 자료 · 최종 검토 기록
      처리 상태와 로컬 자료는 기록일 뿐 변경 승인/자료 진위 인증이 아닙니다. TXT/PDF/PNG/JPEG 파일별 512 KiB·최대 100개를 평문 보관하며 자동 열기/외부 업로드하지 않습니다.
      정확한 HWP/PDF 해시에 연결하는 로컬 확인 기록입니다. 기관 제출 승인·전자서명·직인 효력을 부여하지 않습니다.

      2 · 수정안 확인
      수정 전 / 후 검토
      수정안 직접 작성 · 저장은 승인/적용 아님
      원본의 연결 문구를 선택하고 정확한 교체 문구를 직접 입력합니다. 메모를 자동으로 문구로 바꾸거나 숫자·출처를 추측하지 않습니다. 엄격한 글자 교체 방식만 지원하며 보존 검사 실패 시 범위를 늘리지 않습니다.
      저장하면 아래 서버 수정안 전체를 초안으로 교체합니다. 이전 수정안은 이력에 보존하고 승인 기록은 바꾸지 않습니다. 새 문구는 따로 검토·승인해야 합니다. 실패해도 내 초안을 유지하며 자동 재시도하지 않습니다.
      새 계약: 문구 + 주황색 문단 영역
      기존 두 줄 사이의 빈 공간을 포함하는 최소 문단 외곽 영역입니다. 셀 전체 허용이 아닙니다. 새 문구가 같은 셀 안에서 가운데 정렬될 수 있습니다. 이 영역 밖 픽셀, 표 크기·글꼴·여백·페이지·직인은 그대로 보호합니다.
      선택한 문단의 계산 정보와 미리보기만 다시 만듭니다. 다른 문단·글꼴·표·본문 그림·직인·페이지는 보호합니다.
      이 수정 방식의 정확한 변경 범위
      한글이 선택 문단의 줄 캐시, 커서 위치, 수정 시각, 기본 spine linear 표기, 텍스트 미리보기만 재생성할 수 있습니다. 다른 문단 캐시·스타일·컨트롤·이미지는 변경할 수 없습니다.
      승인한 글자 수정안 적용
      원본·기준 자료는 보존합니다. 별도 확인 후 새 결과 사본을 만들며, 통과 뒤에도 PDF 육안 검토가 필요합니다.
      적용 검사와 실패 처리
      저장한 HWP를 다시 열어 영역 밖 픽셀·쪽수·텍스트·내장 그림을 검사합니다. 실패 시 잠금과 증거를 유지하며 자동 재시도하지 않습니다. 자동 검사는 제출 승인/완성본 인증이 아닙니다.
      

      승인한 Native 계약 별도 적용
      승인한 정확한 문단/표 높이 정책·영역만 새 사본에 적용합니다. 원본·검사·실패 잠금을 보존하며 자동 재시도/제출하지 않습니다.
      

      승인은 적용과 별도입니다. 적용 후에도 형식 검사와 결과 PDF의 최종 육안 검토가 필요합니다.
      

      승인과 실제 문서 수정은 별도입니다.‘승인한 수정안을 적용해줘’라고 요청하세요. 적용 후 원본과 결과를 비교하고 직접 확인해야 합니다.
