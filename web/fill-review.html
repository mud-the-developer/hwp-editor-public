오른쪽의 값이 들어갈 빈칸을 직접 선택합니다. 같은 이름의 칸이 반복될 수 있으니 위치를 확인하세요.

위치 선택 도움말

자동으로 칸을 연결하지 않습니다. 주황색은 선택 가능한 영역, 초록색은 연결된 영역입니다. 다른 항목에 사용 중인 칸은 먼저 위치를 해제해야 합니다. 원본 표·행·열과 정확한 좌표는 각 항목의 ‘원본 위치 정보’에서 확인할 수 있습니다.

위치 초안은 이 탭의 메모리에만 있습니다. 탭을 닫기 전에 위치를 저장하세요.

자료를 읽고 있습니다

서명·직인 없는 양식에만 작성합니다. 표·글꼴·그림·쪽수를 유지하고, 공간이 모자라면 수정하지 않습니다.

입력할 내용

위치 저장은 문서 수정이나 승인이 아닙니다. 저장한 뒤 각 항목의 값·근거·위치를 확인해주세요.

변경 범위 확인과 최종 승인

아래 세 가지를 직접 확인해야 승인할 수 있습니다. 내용을 숨겨도 승인 조건은 바뀌지 않습니다.

머리글 변경의 정확한 대상과 범위

원본 머리글 리소스 하나의 패키지 읽기 순서(linear) 표시를 no로 바꾸는 것을 허용합니다. 원래 의미 유지·yes 생략/명시도 허용하며 본문·글꼴·표·페이지는 변경하지 않습니다.

승인은 이 수정안에만 유효합니다. 문서 적용은 별도 요청이며, 적용 후 결과를 직접 확인해야 합니다.

승인을 저장했습니다. 아직 문서를 수정한 것은 아닙니다.다음으로 도구 사용자에게 ‘승인한 수정안을 적용해줘’라고 요청하세요. 적용 뒤 원본과 결과를 비교하고 직접 확인합니다.
